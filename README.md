# mahiruslu/tap

Homebrew tap for my macOS apps.

## Kadraj

[Kadraj](https://github.com/mahiruslu/kadraj) is an open-source screenshot tool for macOS.

```bash
brew install --cask mahiruslu/tap/kadraj
```

Kadraj updates itself (menu → Check for Updates…), so `brew upgrade` leaves it alone.
The cask is updated automatically by Kadraj's release workflow.
